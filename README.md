# Детекция пламени в стекловаренной печи

Система для автоматической детекции пламени в стекловаренной печи с использованием компьютерного зрения и машинного обучения.

## Основные изменения относительно детекции шихты

### В чем разница?

**Предыдущая задача (детекция шихты):**
- Поиск темных, непрозрачных объектов
- Использование инвертированных порогов
- Фокус на геометрических формах

**Новая задача (детекция пламени):**
- Поиск ярких, цветных областей
- Анализ цветовых каналов (красно-оранжевая гамма)
- Детекция движения/мерцания
- Фокус на динамических, органичных формах

### Ключевые изменения в коде

1. **image_processing.py** - полностью переработан:
   - Новые функции: `enhance_flame_regions()`, `detect_bright_regions()`
   - Цветовой анализ в HSV пространстве
   - Детекция мерцания между кадрами
   - Температурный индекс на основе красного канала

2. **gen_pseudo_masks.py** - обновлен:
   - Использование класса `FlameDetector` для временной фильтрации
   - Улучшенная статистика и отчетность
   - Создание превью для контроля качества

3. **inspect_masks.py** - новые возможности:
   - Множественные стили визуализации (огонь, тепловая карта, контуры)
   - Детальная аналитика по форме и размеру пламени
   - Создание сравнительных отчетов

## Алгоритм детекции пламени

### Этапы обработки

1. **Цветовой анализ** - выделение красно-оранжевых тонов
2. **Анализ яркости** - поиск ярких областей
3. **Детекция мерцания** - сравнение с предыдущими кадрами
4. **Температурный индекс** - соотношение красного и синего каналов
5. **Морфологическая обработка** - улучшение формы областей
6. **Фильтрация контуров** - удаление ложных срабатываний
7. **Временная фильтрация** - сглаживание по времени

### Ключевые параметры

В `image_processing.py` можно настроить:

```python
# Цветовые пороги для HSV
flame_hue_range = (0, 30)      # Красно-оранжевые тона
saturation_min = 100           # Минимальная насыщенность
brightness_min = 150           # Минимальная яркость

# Морфологические операции
close_kernel = (7, 7)          # Размер ядра закрытия
open_kernel = (5, 5)           # Размер ядра открытия

# Фильтрация контуров
min_area = 200                 # Минимальная площадь
max_circularity = 0.8          # Максимальная округлость
```

## Контроль качества

### Визуальная проверка
После генерации масок проверьте папку `data/flame_preview/`:
- `fire/` - огненный стиль визуализации
- `heat/` - тепловая карта
- `contour/` - контурное отображение
- `combined_*.jpg` - сравнительные изображения

### Метрики качества
Система автоматически рассчитывает:
- Процент пламени от общей площади
- Количество обнаруженных областей
- Средний и максимальный размер областей
- Коэффициент округлости (circularity)

## Типичные проблемы и решения

### Плохое качество детекции

**Проблема**: Много ложных срабатываний
**Решение**: 
- Уменьшите диапазон цветов в HSV
- Увеличьте минимальную площадь контуров
- Настройте ROI более точно

**Проблема**: Пламя не детектируется
**Решение**:
- Уменьшите пороги яркости и насыщенности
- Проверьте правильность цветовых диапазонов
- Убедитесь что ROI включает области с пламенем

### Проблемы обучения

**Проблема**: Низкий IoU (<0.3)
**Решение**:
- Увеличьте количество эпох обучения
- Проверьте качество псевдо-масок
- Добавьте аугментацию данных

**Проблема**: Переобучение
**Решение**:
- Уменьшите количество эпох
- Добавьте регуляризацию
- Увеличьте разнообразие данных

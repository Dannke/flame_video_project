# Детекция пламени и шихты в стекловаренной печи

Система для автоматической детекции пламени и шихты в стекловаренной печи с использованием компьютерного зрения и машинного обучения.

## Основные функции включают:

1. Обработка кадров: Анализирует отдельные кадры для обнаружения шихты с использованием адаптивного порогового метода, фильтрации контуров и зонального анализа (ближние/дальние зоны, обнаружение пламени).
2. Коррекция перспективы: Использует кастомную шестиугольную трансформацию для исправления искажений, предоставляя вид "сверху".
3. Зональная статистика: Разделяет область на зоны (например, 0-30%, 30-70%, 70-100% по глубине) и вычисляет проценты, средние значения и стандартные отклонения.
4. Обнаружение пламени: Адаптивное обнаружение пламени для динамической настройки параметров сегментации.
5. Визуализация: Генерирует визуализации, графики (например, распределение во времени) и JSON-метрики для результатов.
6. Параллельная обработка: Поддерживает многопоточность для ускорения анализа больших наборов кадров.

## Проект структурирован вокруг нескольких модулей Python:

shikhta_analysis.py: Основная логика анализа, включая обработку видеокадров и построение графиков.
perspective_transform_hexagon.py: Обработка шестиугольной коррекции перспективы с GUI-настройкой.
improved_shikhta_analyzer.py: Улучшенный анализатор с зональным и адаптивным обнаружением пламени.
run_shikhta_only.py: Точка входа скрипта для запуска анализа по директориям кадров.
polygon_gui.py: GUI для выбора полигональной области интереса (ROI).
image_processing.py: Утилиты для предобработки и обнаружения пламени.

Поток данных: Кадры загружаются из директорий, опционально корректируются по перспективе, анализируются на наличие шихты, и результаты сохраняются в виде JSON-метрик, визуализаций и графиков.

## Требования

Версия Python: Требуется Python 3.11.x для совместимости с библиотеками и функциями, используемыми в проекте.
Зависимости: Все необходимые пакеты перечислены в requirements.txt.
